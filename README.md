# Blinkyboard

following hackclub starter project blinky board! shaped like a flower and smells like one too ;) jk i doubt pcbs have a smell of flowers. 

this has: 10 leds, a ne555p, and a cd4017 :D

the tutorial can be followed here:
https://stasis.hackclub.com/starter-projects/blinky

for my dearest sleepover reviewer, as this was part of stasis and the monthly channel, i didn't know i had to register the time :,). the project has already been approved on stasis tho!
here are my journal entries for stasis:
1. I worked on this as part of a tutorial I ran for Oxford build guild! I followed the tutorial as seen in the starter projects. I started by making the schematic according to the starter project, then placed the components on the PCB. I then created the edge design on illustrator, and then imported them into kiCAD. I placed the parts in a flower pattern, and then to add visual appeal I created the inner flower pattern also in illustrator. Ta daaah done :D
2. After reviewer feedback, i fixed the readme to add a better description and images! i also noticed i did not add the connectors, so i added the footprints and then added them to my pcb. i rewired the board for the added connectors, and then tadaaaaaa done ;D
