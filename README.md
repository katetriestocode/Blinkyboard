# Blinkyboard

following hackclub starter project blinky board! shaped like a flower and smells like one too ;) jk i doubt pcbs have a smell of flowers. 

this has: 10 leds, a ne555p, and a cd4017 :D

this is the final build! it was one of my first soldering experiences but it turned out great!
